HolyMind V1 — Versão Reduzida

Esta é uma versão reduzida e simplificada do HolyMind, disponibilizada gratuitamente para que você possa usar as funções principais sem necessidade de criar uma conta ou compartilhar seus dados.

O que você pode fazer:

  • IA para estudos bíblicos: Faça perguntas e receba explicações sobre trechos da Bíblia usando inteligência artificial (powered by OpenAI)
  • Busca de versículos: Pesquise versículos específicos por livro, capítulo e versículo com dados armazenados localmente em JSON

Por que alguns recursos foram removidos:

Os seguintes recursos foram temporariamente removidos desta versão para garantir segurança e conformidade:

  • Login e contas de usuário: Você não precisa criar uma conta para usar o HolyMind
  • Histórico de conversas: Nenhum dado seu é armazenado no servidor
  • Banco de dados: Mantemos zero dados persistentes de usuários
  • Bíblias em PDF: Evitamos distribuir PDFs protegidos por direitos autorais
